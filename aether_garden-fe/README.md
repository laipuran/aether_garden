# aether_garden Frontend

React + TypeScript personal website frontend.

## Run

```bash
pnpm install
cp .env.example .env
pnpm dev
```

Default frontend URL: `http://localhost:5173`

Set backend API URL in `.env`:

```bash
VITE_API_BASE_URL=http://localhost:5109/api
```

## Build

```bash
pnpm build
```
